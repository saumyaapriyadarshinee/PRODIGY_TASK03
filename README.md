# Classification with Support Vector Machine (SVM)

This project demonstrates the implementation of a **Support Vector Machine (SVM)** classifier, one of the most powerful and versatile machine learning algorithms for classification. The goal is to classify data points into distinct categories by finding an optimal **hyperplane** that maximizes the margin between different classes.

## 📌 Project Overview

This notebook focuses on a fundamental classification task using the SVM algorithm.

**Key Components:**
* **Data Preprocessing:** Standardizing the features.
* **Model Training:** Implementing `SVC` (Support Vector Classifier) from Scikit-learn.
* **Evaluation:** Assessing the model's performance using the **Confusion Matrix** and **Classification Report**.

## 📂 Dataset

The project uses a standard classification dataset (like Iris or similar) with **features** ($X$) and **target classes** ($y$).

## 🛠️ Technologies Used

* **Python 3.x**
* **Pandas & NumPy**
* **Matplotlib & Seaborn**
* **Scikit-learn** (for `StandardScaler` and `SVC`)

## 📊 Methodology

1.  **Data Loading and Splitting:** Load the dataset and divide the data into training and testing sets.
2.  **Feature Scaling:** Apply `StandardScaler` to normalize the features, which is crucial for SVM performance.
3.  **Model Training:** Train the `SVC` model (likely utilizing the **RBF kernel**).
4.  **Model Evaluation:** Generate and interpret the **Confusion Matrix** and **Classification Report** (Precision, Recall, F1-Score).
